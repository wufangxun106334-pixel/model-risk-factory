# Model Risk Factory

EXL × UCD Data & AI Hackathon — Challenge 04 项目准备材料。

## 项目目标

分析模拟旧 R 模型，整理 Model inventory（模型清单），将一个模型移植到 Python，并生成包含等价性、性能、稳定性与公平性证据的验证报告。

## 当前状态

当前仓库处于 Planning（规划）阶段，仅包含解读与 SOP；尚未实现可运行原型。

## 文档

- [项目 SOP](Challenge04_银行模型风险管理_项目SOP.md)
- [活动解读](EXL_UCD_Data_AI_Hackathon_2026_解读.md)

## 计划范围

- 为三个模拟模型建立档案。
- 完成一个 R → Python 模型移植及逐记录等价性测试。
- 使用 Synthetic data（合成数据）演示模型验证。
- 生成可追溯报告，并保留 Human review（人工审核）。

模拟资产和测试结果不代表真实银行生产模型或监管合规认证。活动状态、截止时间和具体规则请以主办方最新通知为准。
