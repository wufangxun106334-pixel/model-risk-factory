# V3 正式 run 决策记录（H-01～H-04）

`docs/v3/formal_run.sh` 只能在本文件四个决定全部填写、签署并提交之后执行。每项的背景、现状和阻塞关系见 [交接清单](08_handoff.md)。
`formal-preflight` 能核验其中可机读的部分：UCI 批准标志、ZIP 与账本、seed 47 未消费、干净工作区和固定 HEAD。审核人与标签策略只能由团队在这里写明。

填写规则：

- 写真实姓名或角色，不写 `agent-delegated`。代理审核的授权本身由人签署。
- 证据写仓库内路径，或者说明存放位置。邮件原文、截图等可以放在 `docs/official/`。
- 时间用 ISO 8601（UTC），例如 `2026-11-12T09:30Z`。
